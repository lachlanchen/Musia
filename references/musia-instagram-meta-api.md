# Musia Instagram Reels

The owner's default for normal Musia Instagram releases is the **Meta Instagram
Content Publishing API**, targeting `@lazyingart`. Keep Instagram out of the
LazyEdit multi-platform dispatch. Do not substitute Meta Business Suite,
Postiz, Selenium, the promotion account, or a Facebook cross-post.

1. Finish the portrait recording. Inspect the lyrics, clock, chord diagram,
   audio, logo and ending. Keep the same reviewed video for delivery.
2. Use the sibling LALACHAN repository's
   `references/publish/instagram-direct-meta-api.md` and
   `scripts/publish_instagram_reel.py`. Verify the exact account, publishing
   authorization and current quota **without** `--publish`.
3. Stage only the approved video using an authorized temporary HTTPS location.
   Use a concise, listener-facing caption. Run the publisher with the local
   master, matching staged bytes, one private receipt, native AI disclosure
   where applicable, and the explicit publication flag.
4. Verify the returned Reel and permalink. A prepared client, previous browser
   receipt or successful upload alone is not an API publication. On an ambiguous
   submit, reconcile the existing receipt; never create another post to test it.
   When credentials are missing, keep the post pending and ask for an
   owner-authorized setup via a private file, never a token in chat.

Shipinhao video, YouTube and Douyin continue through LazyEdit when requested.
Do not infer a separate Shipinhao Music submission from a video request.
