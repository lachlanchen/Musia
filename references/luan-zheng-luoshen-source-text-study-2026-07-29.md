# 乱徵《洛神》原文选段核对

## 结论

用户所指作品是乱徵演唱的《洛神》，不是一首名为《洛神赋》的完整赋文
演唱。歌曲从曹植《洛神赋》的形貌描写中选择原句，重新排序，并把
“翩若惊鸿”四句作为反复副歌。

## 歌曲采用的原文

按歌曲首次出现的顺序整理，并恢复明显的网页转写错误：

```text
秾纤得衷，修短合度。
肩若削成，腰如约素。
延颈秀项，皓质呈露。

飘忽若神，体迅飞凫。

云髻峨峨，修眉联娟。
丹唇外朗，皓齿内鲜。
明眸善睐，靥辅承权。
瑰姿艳逸，仪静体闲。

翩若惊鸿，婉若游龙。
荣曜秋菊，华茂春松。
髣髴兮若轻云之蔽月，
飘飖兮若流风之回雪。

披罗衣之璀粲兮，珥瑶碧之华琚。
戴金翠之首饰，缀明珠以耀躯。
践远游之文履，曳雾绡之轻裾。
芳泽无加，铅华弗御。
```

歌曲把“翩若惊鸿”至“若流风之回雪”反复演唱三遍。

## 与原文的细小差异

- 原文为“体迅飞凫，飘忽若神”，歌曲交换为“飘忽若神，体迅飞凫”。
- 原文为“芳泽无加，铅华弗御”，公开歌曲歌词写成“芳泽无加兮，
  铅华弗御”，多一个“兮”。
- 部分转载页把“瑰姿”误成“壞姿”、把“飘飖”误成“飘飘”；音乐平台
  歌词和原文交叉核对后，应使用“瑰姿”“飘飖”。
- “秾/襛”“修/脩”“峨/峩”“仿佛/髣髴”等存在版本或字形差异。制作
  新歌时先选定一个可靠底本，公开歌词保持该底本一致。

## Musia 默认启示

古诗文歌曲默认采用原文选段：

```text
核对底本
-> 选择最有音乐性的原句
-> 重排、分节、重复、留白
-> 私有发音控制
-> 原文歌词生成
-> ASR + 人耳校正
```

“追求好听”不等于默认改写。现代汉语改编应是单独命名的备选路线。
